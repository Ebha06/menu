# 🍽️ Restro — Restaurant Landing Page

## 📌 Project Overview

A simple and responsive restaurant landing page created using **HTML and CSS**.

### ✨ Features

- Responsive navigation menu
- Restaurant hero section
- Background image with dark overlay
- Circular rotating food image
- Book Table button
- Font Awesome icons

### 🛠️ Technologies Used

- HTML
- CSS
- Font Awesome

### 📚 Learning

This project helped me practice **Flexbox, positioning, background images, CSS animations, and responsive design**.
